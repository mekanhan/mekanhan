### Hi, I'm Mekan

I build **[AuctionMate](https://auctionmate.app)**: research for buying cars at salvage
auctions. What a car is worth, what similar cars sold for, and whether the deal works,
on the web, on iPhone and in Chrome.

Before that, and still: test automation (Java, Selenium, mobile). That turned into two
open-source tools about one question: does your test suite protect what you think it does?

- **[control-arm](https://github.com/mekanhan/control-arm)**: does a test actually fail on
  the code it was written to catch? Rewinds your code to before the fix and runs the test there.
- **[unreached](https://github.com/mekanhan/unreached)**: which of your tests does CI never run?
